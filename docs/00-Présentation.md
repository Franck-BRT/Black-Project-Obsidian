# Black Projects by Black Room Technologies

> Copyright © 2026 Black Room Technologies. Tous droits réservés.

Black Projects est un outil de Black Room Technologies qui travaille **dans votre coffre
Obsidian** : toutes les données restent des fichiers Markdown sur votre machine, lisibles
sans l'outil, et rien ne part sur Internet sans que vous l'ayez configuré.

## Le premier module : analyse d'appels d'offres

Déposer le dossier de consultation (RC, CCTP, CCAP, BPU, DPGF, annexes), en extraire les
exigences, en mesurer la qualité selon l'ISO/IEC/IEEE 29148, interroger tout le dossier,
relever les dates clés, et produire la matrice de conformité et le rapport d'analyse.

L'IA est optionnelle et locale : elle s'appuie sur un serveur compatible OpenAI que vous
désignez, par exemple un serveur interne. Sans elle, l'extraction et l'analyse qualité
fonctionnent entièrement hors ligne.

## Une plateforme modulaire

Black Projects est construit en modules : d'autres fonctions s'ajouteront au même outil
(planning, documents, qualité…), sans changer vos données.
