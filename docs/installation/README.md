## Prérequis

- Obsidian 1.13 ou plus récent, installé depuis [obsidian.md](https://obsidian.md).
- Un coffre Obsidian (un dossier) : de préférence un coffre de test pour commencer.

## Installer le plugin à la main

1. Récupérer les trois fichiers fournis par Black Room Technologies : `main.js`,
   `manifest.json`, `styles.css`.
2. Dans le coffre, créer le dossier `.obsidian/plugins/black-projects/` (le dossier
   `.obsidian` est caché sur macOS et Linux).
3. Y copier les trois fichiers.
4. Dans Obsidian : **Paramètres → Modules complémentaires** ; désactiver le mode
   restreint si nécessaire, puis activer **Black Projects by Black Room Technologies**.

## Vérifier

- **Paramètres → Black Projects by Black Room Technologies** : la liste des modules,
  « Analyse d'appels d'offres » à l'état *Actif*, et la licence.
- Palette de commandes (Ctrl/Cmd + P) : **À propos de Black Projects**.
